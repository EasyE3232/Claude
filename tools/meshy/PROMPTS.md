# Gym Wars: Meshy prompts

One prompt per character, in the order to make them. Ronnie Curlman is done.
Copy a prompt into Meshy **Text to 3D**, or better, make a sheet image first and use **Image to 3D**.
When a model is in your place, name it exactly like the **Name in game** line, e.g. `JoeFlexer`.

## Meshy settings (every character)
- Mode: Text to 3D (or Image to 3D from a front-view sheet)
- Pose: **A-pose** · Symmetry: **on** · Topology: triangle · Target polycount: **~10,000**
- Texture: on (PBR) · Export: **FBX**
- Check before export: arms away from the body, hands not touching the thighs, feet flat

## In Studio (per character)
1. **Avatar tab → Import 3D** → pick the FBX
2. **Avatar → Auto Setup** on it (makes it walk and work out properly)
3. Rename it to the **Name in game** below and drop it in **ServerStorage**
4. Press Play: it walks the carpet automatically
