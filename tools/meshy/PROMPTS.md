# Gym Wars: character prompts (Ronnie Curlman style)

Every character is made the same way Ronnie was: a **character sheet** first, then **Meshy Image to 3D** from it.
That keeps all 40 in the exact same style as Ronnie. Ronnie Curlman is done.

## For each character
1. **ChatGPT (image):** attach **(a)** your reference photo of the real person and **(b)** the Ronnie Curlman sheet image (style guide), then paste the **Sheet prompt**.
2. **Meshy → Image to 3D:** crop the sheet to the **FRONT** full-body view (plain background if you can) and upload it.
   Settings: **A-pose**, symmetry **on**, ~**10,000** polygons, texture **on** (PBR). Export **FBX**.
   No good sheet? Use the **Meshy text prompt** in Text to 3D instead.
3. **Studio:** Avatar → **Import 3D** → **Auto Setup** → rename to the **Name in game** → drop in **ServerStorage** → Play.

Muscle size goes up with rarity (Common = fit gym-goer ... G.O.A.T. = giant), but the proportions and art style stay Ronnie's.
